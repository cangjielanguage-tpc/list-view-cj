## 介绍

multitype4cj 为list组件创建多种条目类型的UI组件库.

### 效果展示


### 特性

- 组件基础属性
- 列表项间距
- 初次加载时起始位置
- 排列方向
- 可编辑模式
- 滑动效果
- 链式联动动效
- 列表项删除时触发器
- 起始位置和终止位置发生变化时触发器
- 吸顶效果
